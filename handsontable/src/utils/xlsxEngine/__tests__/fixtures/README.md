# xlsx fixtures

Two kinds of fixture live here.

## Written by ExcelJS

`formulas`, `layout`, `lossy`, `multi-sheet`, `sparse`, `styles`, `validation`, `values` and
`wide-columns` come from `generate.mjs`. Regenerate them with
`node src/utils/xlsxEngine/__tests__/fixtures/generate.mjs` and commit the output.

## Saved by a spreadsheet app

`libreoffice-saved.xlsx`, `libreoffice-saved-1904.xlsx` and `excel-saved.xlsx` carry the dialects
the apps write, which no writer in this repository produces. `appSavedFixtures.unit.js` reads them
with both engines. They cannot be regenerated by a script in CI, so do not overwrite them.

How they were made:

1. A one-off ExcelJS script (not committed) wrote two source workbooks with the same sheet `Data`:
   a header row, a label column, `"$"#,##0.00` and `#,##0.00"zł"` currencies, a TRUE/FALSE column,
   a `yyyy-mm-dd hh:mm` date-time, an `[h]:mm` duration (0.5, 1.0625, 0.25, 0.125), the defined
   name `Sales` over `Data!$G$2:$G$4` (10, 20, 30) with `=SUM(Sales)` cached as 60, a merge
   `I2:I3`, an inline list validation on `J2:J5`, a `"TRUE";"TRUE";"FALSE"` column of 1 and 0, a
   note on `B2`, a hidden row 5 and a frozen first row. The second source sets
   `workbook.properties.date1904 = true` and stores its date-times 1462 days lower, so both files
   hold the same dates.
2. LibreOffice 26.8.0.3 converted both sources:
   `soffice --headless --convert-to xlsx:"Calc Office Open XML" <source>.xlsx`, with a profile set to
   recalculate on load. The outputs are `libreoffice-saved.xlsx` and `libreoffice-saved-1904.xlsx`.
3. Excel for Mac 16.113 opened the 1900-system source, recalculated it and saved it as
   `excel-saved.xlsx`.

What each app wrote, as read from the parts:

- LibreOffice: `\$#,##0.00` for the dollar format, every typed boolean as a `t="b"` cell with a
  `TRUE()`/`FALSE()` formula, the BOOLEAN-format column as `t="b"` cells, `date1904="true"`, every
  boolean attribute as `"true"`/`"false"`, `<formula2>0</formula2>` on the list validation, an `xf`
  with `horizontal="general" vertical="bottom"` on every cell, and `docProps/custom.xml`.
- Excel: `"$"#,##0.00` kept quoted, typed booleans as plain `t="b"` cells, the BOOLEAN-format column
  as the numbers 1 and 0, `hidden="1"`, and `xl/calcChain.xml`.
- Neither wrote a threaded comment or an `x14` validation for this content.
