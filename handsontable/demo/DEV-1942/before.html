DEV-1942: Skip eager full-grid cell-meta materialization on load

Version: BEFORE fix buggy AFTER fix fixed
Build provenance: Handsontable ?, built from commit 56ec36d2 — the parent of the DEV-1942 fix (38c1f79d, PR #12847). This build predates the fix, so the O(rows×cols) eager scan is present.
Bug: On load, runSourceDataValidators resolves and permanently caches a cell-meta object for every cell in the grid (O(rows×cols)) through getCellMeta(), dominating init time and baseline memory on large grids.

Steps: Click "Initialize Grid". Expect the "cell metas materialized" counter ≈ the full dataset (200,000) and a getCellMeta call per cell. Then compare with the AFTER page.

Demo config notes: autoColumnSize is disabled (fixed colWidths) because its column-width sampling also touches every cell's meta on init and would mask the difference. Calls are counted with the beforeGetCellMeta hook, which runs on every cached meta resolution in both builds.
